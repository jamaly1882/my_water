# محرك قراءة العدادات على الويب (اختياري)

هذا المجلد **فارغ عمدًا** في المستودع. توجد فيه ملفات المحرك فقط إذا
شغّلت:

```bash
bash tool/fetch_ocr_assets.sh
```

## لماذا؟

قراءة أرقام العداد على الويب تستخدم [Tesseract.js](https://github.com/naptha/tesseract.js).
شاشة `index.html` تجرّب المصادر بهذا الترتيب:

| # | المصدر | متى يفيد |
|---|---|---|
| 1 | `web/ocr/…` (هذا المجلد) | الشبكات البطيئة أو التي تحجب النطاقات الخارجية |
| 2 | `cdn.jsdelivr.net` | الحالة الافتراضية |
| 3 | `unpkg.com` | بديل عند حجب jsDelivr |

إن كان المجلد فارغًا يُتجاهَل بسرعة (طلب 404 واحد) ثم ينتقل إلى الشبكة.

## الملفات المتوقعة

```
web/ocr/tesseract.min.js
web/ocr/worker.min.js
web/ocr/core/tesseract-core-lstm.wasm.js
web/ocr/core/tesseract-core-simd-lstm.wasm.js
web/ocr/lang/eng.traineddata.gz
```

الحجم الكلي ≈ 11 ميغابايت، ولا تُطلب هذه الملفات إلا عند أول عملية
قراءة عداد (ليست جزءًا من فتح شاشة الدخول)، وتُخزَّن في المتصفح سنة كاملة.

## ملاحظات

- لا تضف هذه الملفات إلى Git إلا إن أردت أن تعمل القراءة دون إنترنت
  على كل الأجهزة؛ الأفضل تشغيل السكربت على جهاز البناء.
- عند التحديث إلى إصدار جديد من Tesseract أعد تشغيل السكربت ثم
  `flutter clean` قبل البناء، حتى لا يبقى مزيج من إصدارين.
- إن فشلت القراءة رغم ذلك، افتح شاشة القراءة واضغط
  **«تفاصيل القراءة (للدعم)»** وانسخ النص: يبيّن هل المحرك محمّل،
  ومن أي مصدر، ونص آخر خطأ بالضبط.
