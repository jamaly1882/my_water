# قاعدة تدوير القراءة: إغلاق الدور = بداية الدور التالي

## القاعدة

1. عند بداية دور المشترك نصوّر العداد ونثبّت قيمة البداية — مثال: **15000**.
2. عند نهاية الدور ندخل قراءة الإغلاق — مثال: **15200**.
3. الاستهلاك = الإغلاق − البداية = **200 م³**، وهو ما يُحاسب عليه المشترك.
4. **بداية الدور التالي هي 15200 نفسها** — لا 15000 ولا أي رقم آخر.

الهدف: لا فجوة ولا تكرار في سلسلة القراءات. كل متر مكعب يُحسب مرة واحدة.

```
دور ١: بداية 15000  ←  إغلاق 15200   (استهلاك 200)
دور ٢: بداية 15200  ←  إغلاق 15410   (استهلاك 210)
دور ٣: بداية 15410  ←  …
```

## أين تُفرض في الكود

`lib/screens/open_cycle_screen.dart`:

- `loadCarriedReading()` — عند فتح الشاشة يقرأ آخر دورة **مغلقة** للمشترك من
  مجموعة `cycles` (أعلى `cycleNumber` بحالة `Closed`)، ويضع قيمة
  `currentReading` (رقم الإغلاق) في حقل قراءة البداية تلقائيًا، ويعرض
  سطرًا توضيحيًا: `Previous cycle closed at 15200. The new cycle starts from 15200.`
- `saveCycle()` — قبل إنشاء الدورة يتحقق: `قراءة البداية == إغلاق الدور السابق`،
  وإن اختلفت يوقف الحفظ برسالة تُظهر الرقم الصحيح.
- أول دورة للمشترك (لا توجد دورة مغلقة سابقة) تُقبل بأي قراءة.

## حالات خاصة

- **استبدال العداد:** لا يُسمح بالبدء من رقم مختلف آليًا. صحّح سجل الدورة
  السابقة (أو أنشئ دورة تسوية) ثم ابدأ الدورة الجديدة، حتى تبقى السلسلة متصلة.
- **دورة مفتوحة بالفعل:** تُمنع إضافة دورة جديدة قبل إغلاق المفتوحة
  (قاعدة موجودة مسبقًا في نفس الشاشة).

## الاختبار اليدوي (عند توفر Flutter SDK)

1. مشترك بدورة مغلقة عند 15200 ← افتح «فتح دورة»: يجب أن يظهر 15200 في الحقل
   مع السطر التوضيحي.
2. جرّب حفظ 15100 ← يجب أن يُرفض برسالة تُظهر 15200.
3. احفظ 15200 ← تُنشأ الدورة، ثم أغلقها عند 15410 ← الدورة التالية تبدأ 15410.
